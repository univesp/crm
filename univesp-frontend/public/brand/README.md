## Regras

- Nao alterar cores do logo.
- Nao distorcer, comprimir ou aplicar sombra/filtro.
- Nao substituir a marca por texto `UNIVESP` quando houver espaco para o logo.
- Nao usar o simbolo isolado como assinatura principal.
- Altura minima digital: 25px para versao simplificada.
- Usar `alt="Univesp"` quando a imagem for a identificacao institucional principal.
- Usar `alt` significativo nos logos do Governo SP quando forem links institucionais; usar `alt=""` apenas em icones decorativos.
