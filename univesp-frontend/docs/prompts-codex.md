# Prompts Codex

## Objetivo

Guardar instrucoes base para futuras tarefas do Codex no frontend da UNIVESP.

## Prompt para UX do aluno

"Trabalhe apenas dentro de `univesp-frontend`. Evolua a experiencia do aluno usando mocks existentes. Nao integrar com backend real. Priorize FAQ em arvore, registro de atendimento, protocolo, minhas solicitacoes e acessibilidade basica."

## Prompt para UX do OP

"Trabalhe apenas dentro de `univesp-frontend`. Evolua a area do OP com foco em fila operacional, SLA, criticidade, FAQ operacional e escalonamento. Nao alterar backend nem criar dependencia real de API."

## Prompt para UX admin

"Trabalhe apenas dentro de `univesp-frontend`. Evolua a area admin com dashboard, gestao de FAQ, parametros operacionais, permissoes e auditoria. Use mocks e documentacao local como fonte."

## Prompt para mocks

"Crie ou atualize apenas arquivos em `univesp-frontend/mocks` com dados coerentes de aluno, FAQ, protocolo, fila e dashboard. Nao espalhe dados fake pelos componentes."

## Prompt para documentacao

"Crie ou atualize apenas arquivos em `univesp-frontend/docs` com foco em regras de negocio, fluxos, perfis, status, dados e roadmap. Nao implementar pagina nesta tarefa."
